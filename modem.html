D-Modem HTML Terminal

Independent, browser-only modem DSP recreation. The original C++ sources are used as reference, not copied wholesale. The implementation deliberately exposes only standards with a working data pump.

Support status: V.32, V.32bis, V.34, V.90 and V.92 require the full D-Modem DSP handshake and trellis/PCM implementations; they are not claimed by this HTML build. Do not select or advertise them until corresponding DSP and interop tests exist.
