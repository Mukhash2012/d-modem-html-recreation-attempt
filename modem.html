D-Modem HTML Terminal

A standalone browser modem DSP terminal. FSK and QAM modes can generate, record, save and decode local test frames.

Experimental V.32+: the browser build includes V.32/V.32bis/V.34/V.90/V.92-style signal and handshake simulation, but it is not protocol-certified wire interoperation. Use loopback tests for local validation.
